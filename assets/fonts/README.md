# Noto Sans SC

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

The unmodified variable font `NotoSansSC[wght].ttf` is stored as `NotoSansSC-VF.ttf`.
Copyright and the SIL Open Font License 1.1 are included in `OFL.txt` and copied with the font into each program package. The app loads this file locally and never downloads fonts at runtime.

Segoe UI is read from the Windows installation; Microsoft font files are not redistributed.
