# Recall 本地部署与升级（0.5.2）

家里构建、验收和生成发布包；办公室只运行构建好的 Windows 程序，办公室业务数据始终保留在该电脑。无账号、跨环境同步和联网更新服务。

## 首次部署

1. 带 `Recall-0.5.2-Windows-x64.zip` 到办公室，解压整个目录，不能只复制 Recall.exe。
2. 双击 Recall.exe，首次在该电脑使用时选择“首次使用，建立新记录”；已有旧版记录则选择“接续旧版记录”和原 data 文件夹。建立指向它的快捷方式。不需要 Node.js、npm、Git 或项目源码。
3. 正式数据固定在 `%LOCALAPPDATA%\Recall\data`，备份在 `%LOCALAPPDATA%\Recall\backups`；设置页显示实际位置。运行缓存另存 `Recall\runtime`。
4. 使用 AI 时，选择办公室本机 OpenCode v2 CLI 和模型，使用其已有认证。包中没有家里的任务、路径设置或认证。模型不通时仍能正常记录、查找、修改和保存。

## 后续升级

从0.4开始，打开工作台“设置与数据”→“选择离线更新包”，选择比当前版本更新的完整 Windows ZIP。核对预览版本后确认：程序等待所有窗口草稿落盘、做完整业务备份，再退出并由独立辅助进程替换清单中的程序文件、重新打开。

解压前验证路径、条数和大小，解压后核对 SHA、版本和必需组件；预览后有变化则拒绝更新。程序目录中未列入旧清单的同名用户文件不会被覆盖，目录联接/符号链接会阻断替换。替换前保留旧程序，复制失败核验恢复结果；结果与错误在 `%LOCALAPPDATA%\Recall\runtime\updates\<UUID>`。失败后保留此目录，不要自行覆盖数据目录；更换失败发生在新程序启动前才自动恢复旧程序，新程序启动后不自动降级数据库。

清单和 SHA 用于发现损坏或文件变化，不是发布者签名；只使用本开发会话提供的完整包。无联网下载、差分更新或自动降级合并。

首次从0.3或更早版本升级，没有应用内更新入口，仍按下面步骤手动更新：

1. 保存当前输入，从托盘退出 Recall，不能只关闭窗口。
2. 解压新版到程序目录，或另一个程序目录；更新快捷方式。不要覆盖固定 data，也不要拿家里的数据库替换办公室数据库。
3. 新版读取原数据位置。在程序版本变化或数据库结构升级时先生成完整业务备份，校验数据库记录、附件和草稿文件，再迁移结构。
4. 迁移在事务内完成，版本号在成功时更新；失败会停止启动并保留原库，不自动创建空库。比程序更新的数据库版本拒绝写入。
5. 确认工作台中的已有事项、历史进展、资料和模型设置均可使用。

## 从 0.1 便携版接续

原数据位于旧 Recall.exe 旁的 data。首次升级把新版程序文件放回该目录（保留 data）后启动，或首次打开新版时选择“接续旧版记录”。程序先将旧业务数据快照复制到备份，再复制到固定目录、校验后接续；不删除或改写旧 data。

固定目录与便携目录都有数据库且没有接续记录时停止提示；接续后旧目录又有新修改也停止提示。此时两份数据都保留，需要核对后接续，不能自行覆盖或合并。不要再次运行旧 0.1 来记录；它还没有未来版本保护。

内部附件使用相对 data 的路径，程序或整个数据目录搬迁后可以继续读取。原位资料引用仍保存外部完整路径，不移动原文件；外部文件迁移后需要重新关联。

## 备份与恢复

业务备份包括 SQLite 一致快照、日志、附件、草稿附件、提醒状态和本机设置；不复制 Chromium 缓存或 OpenCode 认证。每天数据有变化时自动备份一次，原升级前备份继续执行。

1. 工作台“设置与数据”可“立即完整备份”，查看最近成功时间、失败提示和备份位置。选择其他磁盘可降低同盘损坏风险；原位引用文件需另外保管。
2. 点击“选择备份恢复”，选择具体备份文件夹，核对时间、事项/记录/附件/草稿数量。旧格式备份会标识仅通过当前完整性校验。
3. 点击“核对并恢复”，在原生确认框确认。程序等待窗口草稿落盘、校验并暂存迁移、备份当前完整数据、关闭数据库并切换，再重新启动。取消不会更改现有记录。
4. 恢复回到备份时点，之后的新记录不会合并；恢复前完整目录保存在 data 同级的 `data-before-restore-<UUID>`，并有 before-restore 完整备份，可再次选择其恢复。原备份文件不改写。日常备份位置沿用当前本机选择。
5. 本版保留已有备份，不自动清理；请定期查看磁盘空间。手动移动或处理原始数据目录前，先保存并从托盘退出程序。不能直接用旧数据库覆盖当前库。

升级包同时提供 SHA-256 和程序文件清单。发布包不包含 data、业务备份或认证；不提供安装器或自动降级合并。

## 后台与快捷入口

设置页可选择登录后在托盘运行，默认关闭；只在用户保存时修改当前用户登录启动设置。双Shift和Ctrl+Alt+Space用于统一输入；独立资料窗口及Ctrl+Alt+L注册已取消，链接集中在工作台。关闭窗口只收起，托盘或设置页退出才结束后台。

## 到点提醒与办公室试用

回访和截止按用户设置的时刻提醒，程序运行中每30秒检查；退出或关机期间下次启动补查，休眠后唤醒补查。未处理提醒在工作台顶部，可打开事项、延后10分钟/明天此时或标记本次已处理。延后不改变原截止，查看/处理提醒不计实际推进。

便携正式版启动时建立/更新当前用户开始菜单的 Recall 快捷方式，以支持 Windows 原生通知。通知失败或 Windows 不显示横幅时，工作台未处理入口仍保留。升级后建议用无敏感样例设置一次近期回访，检查通知和点击进入事项；完全退出程序时不会后台通知。

首次办公室运行权限、远程桌面输入法、多显示器缩放及办公室 OpenCode 连接需在目标电脑验证。
