# OpenCode 接入与资料范围

## 当前行为

Recall只调用用户选择的本机OpenCode CLI，复用其认证和所选模型；不直接管理模型提供商密钥。可沿用OpenCode新会话默认模型，或从可用目录中明确选择模型。

整体优先级、单事项相对优先级和开展建议仅由用户点击启动。保存、搜索、查看、提醒处理与本地接续建议均不自动调用模型。

## 发送范围

仅包含已保存事项的文字、用户填写的时间/象限、现场、下一步、等待信息、任务状态，以及已保存记录文字和实际推进时间。草稿不发送；不读取附件、附件名称、文件夹内容或引用目标内容。最多100项、6万字符。

用户属性和实际推进不得被模型改写。分析结果、失败、中断状态、模型标识、CLI版本、时间及上下文哈希独立保存在本机SQLite。

## 调用与失败处理

使用OpenCode v2的独立standalone运行，正文经stdin传递，专用运行目录、全部工具权限拒绝、60秒超时，同时只执行一个分析。模型服务可能位于本机之外，OpenCode也可能保存其会话；Recall不复制认证。

免费服务拒绝外部调用时明确显示原因，用户可以选择已认证且允许外部调用的模型；不会静默切换提供商。默认模型代表CLI新会话默认值，不保证与OpenCode桌面当前对话相同。退出后的中断分析在下次启动标为失败。

CLI路径通过本机选择器和应用配置确定，不要求修改系统PATH。连接检查只发送固定检查句子；模型验证和样例推理应取得该轮明确授权，常规测试不调用真实模型。

## 后续范围

附件、文件夹及网页内容分析尚未接入。未来扩大上下文范围须明确用户主动选择、读取边界、体积限制、失败反馈和实际验证；不得因目录关联自动扫描或上传业务资料。

本机路径、账号认证状态和原始模型验收记录仅本地保留，不上传仓库。
