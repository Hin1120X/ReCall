# 0.4.0 操作与优化记录

本轮按已确认的前十三项开发。下列记录来自代码检查、隔离样例自动检查及桌面观察；没有使用真实办公内容或调用模型。正式发布验收结果在 implementation-plan.md 更新。

| 优先级 | 发现 | 处理与状态 |
| --- | --- | --- |
| P0 | 旧库有效WAL、诊断启动与退出边界需要单独验收 | 增加真实v5结构+已提交WAL样例，多进程正常启动/退出/重开检查；无隔离目录的诊断只读；退出显式checkpoint。原0.3异常未复现，根因仍待定位。 |
| P0 | v5内部附件路径不应被新迁移重写 | 保留v4及以后合法相对路径，仅更早结构转路径；逐字段、草稿和文件内容回归。 |
| P0 | 更新碰到程序目录的同名用户文件或联接 | 替换前阻断冲突；包括断链和清单文件在内统一验证路径。复制失败核验旧程序恢复，失败细节与旧程序保留。 |
| P1 | 安排面板内Enter可能误提交，按钮Enter可能被拦截 | 面板Enter只关闭；按钮保留原生激活，增加真实sendInputEvent回归。 |
| P1 | 资料面板草稿尚未保存时备份/退出可能遗漏 | 未保存编辑保留在窗口，阻止备份/退出并提示保存或取消，测试已覆盖。 |
| P1 | 跨窗口同一事项/目录可能被旧版本覆盖 | 事项、草稿及目录有版本冲突提示；批量归类逐项检查，部分失败明确显示。 |
| P1 | 选择资料预填新任务时覆盖当前输入 | 已有正文/附件或关系草稿时拒绝覆盖；先保存或处理当前草稿。 |
| P1 | 独立资料窗口可搜索但缺少键盘打开 | 增加搜索框↑↓选择和Enter打开、明确选中样式及输入法保护；与快捷“常用”入口一致。 |
| P2 | 快览中同名资料重复显示且蓝色标签不能打开 | 修正为仅保留下方明确可打开的资料入口；组/人保留标签。 |
| P2 | 快览顶部检索词与任务正文相同，像两个编辑框 | 顶栏placeholder、可访问名称与状态行明确它是检索框，输入后返回结果。 |
| P2 | 详情修改其他字段可能把时间秒/毫秒截断 | 未触碰的时间沿用原值；关系排序变化也不冒充内容修改。 |
| P2 | 多关联时新建紧凑条、安排面板高度受限 | 当前可滚动，快捷时间按钮无需滚动；后续按办公室实际任务长度决定是否做按内容增高，避免再出现尺寸累积。 |
| P2 | 列表批选方框与完成圆圈不易一眼区分 | 已有独立可访问说明；本轮保留操作，下轮可把批选收进按需模式，待日常试用反馈。 |
| P2 | 拼音多音字和同名相关人存在歧义 | 支持人工别名，不引入角色/组织树；有实际样例后再调整匹配。 |
| P3 | 常用页快捷提示重复 | 合并说明，保留类型、固定与最近使用信息。 |
| 待目标环境 | 远程桌面输入法、不同显示缩放、办公室系统策略 | 本机组合输入保护及尺寸回归不能替代目标环境验收；收集实际问题后再改。 |
| 后续 | 系统通知横幅点击、开机登录链路、签名安装包 | 本轮不重启电脑、不变更实际自启动偏好；保留日常试用检查项。离线包SHA是完整性校验，非发布签名。 |

本轮不开发材料内容AI分析、账号同步、人员派发、分组层级、自定义字段配置器或自动备份清理。
