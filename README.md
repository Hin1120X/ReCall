# Recall

ENFP‘s Working kit that make sure every mission is keeping on track

Windows 本地桌面工具：快速记录、找回任务与资料、接续上次工作。无账号、云端数据库或跨电脑同步；原始交接与 prototype 仅在本机保留作参考，不上传仓库。

当前开发版本 **0.5.0 / 数据库版本7**。发布、部署及实际验证状态见 [实施记录](docs/implementation-plan.md)，后续打磨见 [优化记录](docs/optimization-log.md)。

软件发布入口：[下载最新 Windows 版本](https://github.com/Hin1120X/ReCall/releases/latest)。请下载 Assets 中的完整 Windows ZIP，办公室无需安装开发环境；Source code 是源码归档。后续升级见 [发布与升级说明](docs/github-releases.md)。

## 日常使用

- 双击 Shift 或 Ctrl+Alt+Space 呼起紧凑输入条，直接输入搜索任务、链接、地址、别名或拼音。Tab 在全部／待办／链接切换，Shift+Tab 反向；范围切换保留文字及分组。
- 空输入按 ↓ 看本地工作建议：一项主建议、最多两项备选，显示依据、已有现场与下一步。打字切搜索，清空回建议；重新呼起恢复输入条。
- 输入开头的 `+`，Tab 选新增待办／链接，Enter 进入录入；搜索中 Ctrl+Enter 直接新建待办。待办只写正文，链接只贴网址或本地完整路径，Enter 保存；无搜索结果时 Enter 不创建。
- Enter 打开任务详情或系统链接。Esc／关闭窗口只收起，托盘或设置页退出才结束程序。草稿保存在本机，不因再次呼起而覆盖。
- 输入 `#分组名` 并选择候选后形成明确的组内筛选；普通文字命中分组名字不会自动展开全组。任务和链接共用分组，一个条目可以属于多个组，不预建项目组。
- 新建待办可选用 `#分组`、`@链接`、`to 姓名` 关联；候选 Enter／Tab 先确认关联，中文输入法确认文字不触发保存。相关人只用于自己跟踪，不发送消息。
- 工作台只有未完成／已完成两个任务视图，等待、暂停、未来提醒也能找到。紧急／重要、提醒、截止和周期显示为属性标签，点击或“＋属性”打开小弹窗修改；不要求新增时填写。
- “留断点”保存当前现场、可选下一步和一条历史。断点、普通备注、查看、属性修改及 AI 都不算实际推进；只有明确追加实际进展才更新推进时间。
- 链接在工作台集中维护，可编辑名称、别名、分组、固定及归档；网址、文件和文件夹统一按链接使用。原位置不搬动；程序、脚本及快捷方式不从资料入口启动。

附件收存与原位引用仍分开：收存保存副本，关联资料只保存原位置。重复任务完成后生成独立下一期，历史和附件留在本期，不批量补出遗漏周期。

## 外观

跟随 Windows 明暗。快捷窗口在系统支持时使用原生磨砂；减少透明度、高对比度或不支持材质时使用相应实底。工作台主要阅读区域为实底。

中文随软件携带 Noto Sans SC，英文数字使用系统 Segoe UI。字体和许可证在程序 `resources/app/dist/fonts` 中，无需联网或另行安装字体。

## 数据与升级

正式数据固定在 `%LOCALAPPDATA%\Recall\data`，备份默认在 `%LOCALAPPDATA%\Recall\backups`；设置页显示实际路径。程序包不包含任务、附件、草稿、公司资料或 OpenCode 认证。

每天数据有变化时自动完整备份；可手动备份、另选位置并预览恢复。恢复回到备份时点，不合并之后的记录，恢复前会保全当前完整数据。外部原位文件需另外备份。

升级先备份，在事务中增量迁移；拒绝写入未知的更高版本数据库。保留稳定 ID、旧字段、记录、扩展数据、草稿及原文件内容，详见 [数据规则](docs/data-format.md)。

完整解压 Windows ZIP 即可部署，无需 Node.js、npm 或 Git。从0.4开始可在设置与数据选择较新完整离线 ZIP，校验、保存草稿、完整备份后退出替换并重开。手动升级请先保存并从托盘退出旧版，再启动新版、更新快捷方式；只替换程序，保留办公室的数据目录。见 [部署与升级](docs/deployment.md)。

## OpenCode

手动分析保留在折叠区域。选择本机 OpenCode CLI 和模型，复用其认证；仅主动点击分析时发送已保存文字、现场及用户属性。扩展字段、附件和引用目标内容不读取。日常搜索、建议及保存不依赖模型；本轮不接入翻译和缩略语数据源。

## 开发与验收

`npm run typecheck`、`npm test`、`npm run build`；`npm run test:desktop` 使用隔离样例，验证实际全局双击 Shift、窗口前台焦点、录入检索、跨窗口草稿及工作台，不调用模型。

`npm run package` 生成独立 `release/Recall-0.5.0`、Windows ZIP、程序清单与 ZIP 校验值，不覆盖旧版正式目录。`node scripts/check-lifecycle.mjs --exe D:\ReCall_Dev\release\Recall-0.5.0\Recall.exe` 验证旧结构样例的迁移、正常退出及重开，不接受正式 `release/Recall` 程序。

远程桌面、办公室真实输入法、系统通知横幅点击及显示器增减仍须目标环境试用。0.3部署曾出现未定位的数据库完整性异常；后续保护和隔离生命周期验收不能代替对原异常根因的定位。GitHub源码与Release发布流程见 [发布说明](docs/github-releases.md)。
